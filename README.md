## Run localy

Step 1: Clon the repository:

```bash
git clone https://github.com/ChitrakshKataria/portfolio.git
cd portfolio
```
Step 2: Install dependencies 
```bash
npm install
```
Step 3: Run the development local server
```bash
npm run dev
```

## Want to make it your own?
Edit the **siteConfig.ts** file in /portfolio/lib. Replace all of my infoamation with your own. Feel free to edit and add to the site as much as you want.
